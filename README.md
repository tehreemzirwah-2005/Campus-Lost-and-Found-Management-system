# Campus Lost & Found Management System

## Project Overview
The Campus Lost & Found Management System is a web-based application designed to help students report lost and found belongings within the campus.

## Problem Statement
Students often face difficulties finding their lost belongings because there is no centralized system to manage lost and found items.

## Project Objectives
- Provide a platform to report lost items.
- Allow users to report found items.
- Make it easier to search for lost belongings.
- Allow students to submit claims for found items.
- Help administrators manage and verify reports.

## Main Features
- User Registration and Login
- Report Lost Items
- Report Found Items
- Search Items
- Claim Items
- Admin Dashboard
- Item Status Management
